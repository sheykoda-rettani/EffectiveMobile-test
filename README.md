# Запуск тестов

## Выполнение тестов и генерация отчетов

### Сборка проекта
```shell
  mvn clean install
```

### Генерация отчета Allure:
После выполнения тестов автоматически создаются файлы результатов в директории `target/allure-results`.<br>
Для генерации HTML-отчета выполните команду:
```shell
  mvn allure:serve
```
Эта команда откроет отчёт в браузере.

### Примечания
* Перед каждым новым прогоном тестов очищается кэш и временные файлы.
* Результаты сохраняются в каталоге target/allure-results.
* Если хотите просмотреть старый отчет, используйте команду 
```shell
  allure serve path_to_results_folder
```
Пример просмотра старого отчета::
```shell
  allure serve "D:\Idea projects\EffectiveMobile-test\target\allure-results"
```
